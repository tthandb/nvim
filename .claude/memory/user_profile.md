Uses Neovim as their primary editor with a custom Lua config. Actively maintains the config as a dotfiles repo at `~/dotfiles/.config/nvim`. Works primarily with TypeScript/JavaScript (and related web stack). Does not use Python in Neovim. Uses macOS (Apple Silicon) as primary machine but also supports Linux (the install.sh targets both). Uses tmux alongside Neovim. The config is also symlinked/shared with VSCode/Cursor via a vscode compat guard in init.lua.
